CHECKLIST GIT DAN GITHUB
1. Buka terminal di VS Code, pastikan lokasi terminal adalah folder KossBill-Modul7.
2. Jalankan git init.
3. Buat minimal 5 commit deskriptif sesuai contoh di README. Commit harus dibuat oleh kamu/kelompok dan menggambarkan perubahan nyata.
4. Buat repository PUBLIC baru di GitHub.
5. Hubungkan remote menggunakan URL repository milikmu, lalu git push.
6. Tambahkan URL GitHub ke README dan PRD setelah repository benar-benar tersedia.
Jangan mengisi URL palsu dan jangan mengklaim repository sudah publik sebelum memeriksanya.
